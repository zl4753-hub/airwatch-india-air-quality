# AirWatch India: Exploring Air Pollution Through Data Visualization

## Project Overview
AirWatch India explores historical air pollution measurements across Indian
locations using Python, Pandas, Matplotlib, Seaborn, and Jupyter Notebook.

## Research Question
How do recorded air pollutant concentrations vary across Indian locations
and over time, and what temporal, regional, and seasonal patterns can be identified?

## Objectives
- Explore historical pollutant trends.
- Compare pollution measurements across locations and states.
- Investigate monthly and seasonal variation.
- Examine relationships between pollutants.
- Evaluate the feasibility of a baseline predictive model.

## Dataset
India Air Quality Dataset:
https://www.kaggle.com/datasets/shrutibhargava94/india-air-quality-data/data

The dataset covers historical records, with the available date range and
pollutant coverage documented in the notebook.

## Tools
- Python
- JupyterLab / Jupyter Notebook
- Pandas and NumPy
- Matplotlib and Seaborn
- Scikit-learn

## How to Run
1. Clone or download this repository.
2. Install the dependencies listed in `requirements.txt`.
3. Obtain the dataset from Kaggle if it is not included in the repository.
4. Open `AirWatch_Group7.ipynb` in JupyterLab.
5. Update the CSV path if needed and run the notebook cells in order.

## Limitations
The dataset has missing values and uneven monitoring coverage.
Pollutant concentrations are not equivalent to AQI, and exploratory
relationships do not establish causation.
